# SIGN Examples

Worked examples covering all major SIGN constructs.

| File | What it shows |
|---|---|
| [01-canon-index.sign](01-canon-index.sign) | Layer 1 index — 9-document corpus, ~400 tokens |
| [02-full-document.sign](02-full-document.sign) | Complete `std` document — skill definition standard |
| [03-clusters.sign](03-clusters.sign) | All four cluster types with threshold semantics |
| [04-inference-rules.sign](04-inference-rules.sign) | Inference rules and constraints |
| [05-crosswalk-provenance.sign](05-crosswalk-provenance.sign) | Crosswalk mappings and provenance chains |

These examples use the Career Highways workforce intelligence ontology as their subject domain.
The constructs are domain-agnostic and apply to any governed knowledge graph.
